# Logo options for TimeGovern

## Brand name
**TimeGovern** · timegovern.com  
Feel: precise, global, trustworthy (not playful).

## Option A — Globe mark (recommended default)
- Simple globe icon in a rounded square
- Gradient blue → cyan (matches time / sky)
- Wordmark: **TimeGovern** with `.com` in muted cyan
- Best for: header, favicon, app icon

## Option B — Clock + arc
- Minimal clock face or sun arc + horizontal line (horizon)
- Suggests time + earth rotation
- Best for: premium / editorial look

## Option C — Monogram **TG**
- Bold letters in a circle or squircle
- Fast to recognise at small sizes (favicon 16–32px)
- Best for: mobile tab, social avatar

## Option D — Wordmark only
- No icon; strong typography only
- Clean like Stripe / Linear
- Best if the product UI is already dense

## Recommendation
**Start with A (globe mark) + Inter/Jakarta fonts.**  
Easy to implement in code, works dark and light, matches “global time” meaning.

When you pick A/B/C/D we lock it in the lab header, then copy to production later.
